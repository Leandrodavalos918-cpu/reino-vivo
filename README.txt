REINO VIVO v0.2
================

Este paquete es la siguiente etapa del prototipo. Incluye:
- Frontend web responsive.
- Backend FastAPI.
- Base SQLite para persistencia.
- Mundo inicial: 2 reinos, 2.000 habitantes.
- Motor de tiempo y avance de días.
- Eventos, personajes, ciudades y gobiernos.
- Intervenciones básicas del Creador.
- API separada del navegador.

IMPORTANTE:
Esta versión todavía NO es un sitio público en Internet.
Para jugar localmente en una PC:
1. Instalar Python 3.11+.
2. Abrir una terminal dentro de esta carpeta.
3. Ejecutar: pip install -r requirements.txt
4. Ejecutar: python server.py
5. Abrir: http://127.0.0.1:8000

El siguiente paso será desplegar este proyecto en un servidor para que se pueda abrir desde iPhone mediante un enlace público.
